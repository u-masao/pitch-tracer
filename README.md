# **PitchTracer**

## アプリの URL

https://u-masao.github.io/pitch-tracer/

## **概要**

**PitchTracer** は、ブラウザ上で動作するリアルタイム・ピッチ分析ツールです。マイクから入力された楽器や声の音程をリアルタイムで解析し、その軌跡をグラフ上に可視化します。  
個人の練習や演奏のレビュー、音程の安定性を確認するのに役立ちます。

## **主な機能**

* **リアルタイムピッチ検出**: マイクからの音声をリアルタイムで解析し、音名、周波数（Hz）、および基準音からのズレ（cent）を表示します。  
* **ピッチの可視化**: 検出したピッチの推移を時系列グラフにプロットします。これにより、ビブラートやポルタメントなどの音程変化を視覚的に確認できます。  
* **インタラクティブなグラフ**: グラフはマウス操作で自由にズームやパンが可能です。気になる部分を拡大して詳細に分析できます。  
* **カスタマイズ可能な設定**:  
  * **A4基準周波数**: A4（ラの音）の基準周波数を自由に設定できます（例: 440Hz, 442Hz）。  
  * **キー設定**: 楽曲のキー（調）を設定すると、そのキーに含まれる音のガイドラインがグラフに表示されます。  
  * **分析ウィンドウ**: 解析の精度と応答性のバランスを調整できます。  
  * **移動平均**: グラフの表示を滑らかにし、細かなブレを抑制します。  
* **プライバシー**: 音声データはすべてお使いのブラウザ内で処理されます。サーバーにデータが送信されることは一切ありません。ページトラッキングもしてません。

## **技術的なハイライト**

* **ピッチ検出アルゴリズム**: 高い精度を持つ **YINアルゴリズム** を採用しています。  
* **高精度補完**: 離散的な解析結果を補完するため、安定性と精度に優れた **ガウス補間** を実装し、より滑らかで正確なピッチ推定を実現しています。  
* **フロントエンド**: HTML, CSS (Tailwind CSS), JavaScriptのみで構築されており、特定のフレームワークに依存しません。グラフ描画には **Chart.js** を使用しています。

## **使い方**

1. ブラウザで [index.html](https://u-masao.github.io/pitch-tracer/) を開きます。  
2. 「開始」ボタンをクリックし、ブラウザのマイクへのアクセスを許可します。  
3. マイクに向かって楽器を演奏するか、歌を歌います。  
4. 画面にリアルタイムでピッチが表示されます。  
5. 必要に応じて、画面上部のコントロールパネルから各種設定を調整してください。
