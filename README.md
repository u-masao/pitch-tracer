# PitchTracer

楽器練習のためのリアルタイム・ピッチ可視化ツール (A real-time pitch visualizer for instrument practice.)

## 概要

ヴァイオリン等の楽器練習において、演奏中のピッチ（音程）のズレは感覚的に把握しづらい課題があります。本アプリケーションは、マイクから入力された演奏音をリアルタイムに分析・可視化することで、客観的なフィードバックを提供し、練習の質と効率を向上させることを目的としています。

## 主な機能

- リアルタイムでのピッチ分析とグラフ描画
- 録音の開始・停止制御
- 基準ピッチ（A4）の周波数設定
- 選択したキーに合わせた音階ガイドの表示
- インタラクティブなグラフのパン・ズーム機能
